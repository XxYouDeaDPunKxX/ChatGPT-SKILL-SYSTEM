# SKILLS

This directory is a physical deposit for installed skill packages.

It is intentionally empty in the core package except for this README.

This README is descriptive only.

It is not mountable.

It must not be declared in `SYSTEM_CORE/MANIFEST.json`.

It must not be used as a list of active skills.

A skill folder present here means the skill is installed physically.

It does not mean the skill is active in the session.

Only `SKILL <name> LOAD` makes an installed skill semantically active.
